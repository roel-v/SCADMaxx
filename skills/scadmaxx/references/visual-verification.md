# Comparable visual evidence

Choose views that expose likely errors. Begin with broad coverage of silhouette, cavities, repeated features and
interfaces; an oblique view often reveals relationships that one projection hides. Add close or section views
when they answer a concrete uncertainty. There is no mandatory number of cameras.

During refinement, repeat the baseline camera, projection, framing and relevant display settings. Retain additional
views of changed interfaces. Compare the same parameter set and geometry state; a stale live result must not serve
as evidence for current text. Follow [agent workflow](agent-workflow.md) for capture/result guards.

For image replication, match the supplied reference's camera before interpreting silhouette differences. Overlay
images when a verified tool makes alignment meaningful; mismatched perspective can masquerade as a geometry error.
For mesh edits, use actual geometry checks for measurable features rather than estimating from pixels.

Final coverage should show the requested interfaces and form, including openings and previously occluded regions
that matter. Inspect exported output when that is the deliverable. State which views/checks were actually obtained
and what remains uncertain. A visually plausible view, a watertight mesh and a valid source each answer different
questions; combine them as needed through [inspection](inspection.md).
